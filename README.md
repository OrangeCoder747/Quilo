# Quilo
This is a modloader for Chrome that can allow you to inject code into websites. You can create mods, run mods, or get published mods from the Marketplace! Download on Chrome Web Store.

It's not finished yet but if you want to try it out just download all of these files, put them into one folder, open Google Chrome, in the search bar type `chrome://extensions`, then make sure you have Developer Mode turned on in the top right, then click **Load Unpacked** at the top left, then click on the folder that you have created with all of these files in it. This should put an extension called Quilo into My Extensions.

After that, you can open the extension! **Note: There may be errors, as the code is not finished.**
